Speech-to-Text (STT) Flow

From microphone capture to direct cursor paste or automatic note tab creation.

1Capture Audio

Hold Ctrl+Win or click the microphone symbol in the bubble. Silence is filtered locally; audible voice lights the equalizer red.

→
2Transcribe (STT)

Releasing sends 16 kHz PCM WAV slices to api.openai.com (gpt-transcribe) using your locally encrypted API key.

→
3Direct Paste

If an editable input field is focused, OpenFlow copies the formatted transcript and injects Ctrl+V directly into the target window.

→
4Auto Note Tab

If no text field is focused, OpenFlow saves the transcript as a new note and automatically opens and selects its tab.
