Speech-to-Text (STT) Flow

Identical audio pipeline whether using the bundled local Parakeet v3 model or OpenAI API.

1Capture Audio

Hold Ctrl+Win or click microphone in the bubble. Silence is filtered locally; audible voice lights the equalizer red.

→
2Transcribe (Local or API)

16 kHz WAV slices go either to the warm background Parakeet v3 model on your PC or to OpenAI gpt-transcribe.

→
3Direct Paste

If an editable input field is focused, OpenFlow copies the formatted transcript and injects Ctrl+V directly into the target window.

→
4Auto Open Note

If no text field is focused, OpenFlow saves the transcript as a new note and immediately opens it in the Notes editor.
